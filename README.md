# ITECH Computer Education — Bilingual Dynamic Website

## Language
- Default language: English
- Language selector: top-right in the top bar
- Options: English / বাংলা
- Selected language is remembered in the browser using localStorage.
- Course cards, navigation, hero, sections, admission modal, CTA and testimonials switch language dynamically.

## Existing features
- Responsive premium one-page website
- Dynamic course filtering
- Admission/enquiry modal
- WhatsApp pre-filled enquiry
- Gallery lightbox
- Animated statistics counters
- Testimonial slider
- Mobile navigation
- Scroll-reveal animations
- Real campus/gallery visuals from the supplied website assets

## Run
Open `index.html` in Chrome or Edge.

This remains a static website; the language selector and all front-end interactions work without a server.
